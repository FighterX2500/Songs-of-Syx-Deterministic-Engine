# Archive

Finished plans, notes, audits and spike reports, kept as history. They are not kept up to date: what is still true has been folded into `docs/requirements.md`, `docs/architecture.md`, `docs/api.md`, `docs/hooks.md`, the ADRs in `docs/decisions/` and `docs/plan/HANDOFF.md`, which win wherever they disagree with a file here.

Code comments, the rig and ADRs cite some of these files by name (for example "plan 0006", "plan 0013"); that is why they stay in the repository.
