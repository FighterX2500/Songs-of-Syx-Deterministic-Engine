# SOSDET 0.1

SOSDET makes Songs of Syx run the same on every PC in a multiplayer game. The same save, seed and players' commands give the same simulation, step by step.

It is an engine, not a game mode, and does nothing by itself. SoS GSG MP, the multiplayer mod, starts it and carries the data between PCs.

## What you need

- Windows.
- Songs of Syx V71, build 71.44. No other build is supported.
- SoS GSG MP, to play.

## Installing

1. Subscribe to SOSDET and SoS GSG MP on the Steam Workshop.
2. Enable both in the game's launcher, SOSDET ahead of SoS GSG MP.

To install from the release zip instead, copy its `SOSDET` folder to `%APPDATA%\songsofsyx\mods\`, then enable it.

Every player needs the same game build and the same SOSDET build.

SOSDET changes no game files. Untick it in the launcher and the game is the plain game again.

## What it does

- **Lockstep:** every PC runs fixed steps, and each player's action applies at the same step on every PC.
- **Players:** up to 16 share one world map, and each PC runs its own player's city.
- **Between players:** deals, tariffs, vassalage and war.
- **Battles and sieges:** battles between players, allies on one side, sieges and assaults on a capital.
- **City viewing:** a player can watch another player's city.
- **Desyncs:** the PCs compare the game's state every 30 steps. The host can hold the game and resync it.

## With no multiplayer game running

Until a mod starts a session, the game simulates as the plain game, with small differences:
- Captive counts after a battle differ slightly.
- Two small fixes apply: a stats total on load, and a held slider button.
- Path finding uses a faster list, meant to find the same paths.
- Saves made with SOSDET on hold seven extra sections. Whether such a save loads with SOSDET off has not been checked, so keep a copy.

## Known limits

- **Game build:** SOSDET doesn't check the game's build when it starts. On another build it can crash or split. After a game update, wait for a new SOSDET.
- **SOSDET build:** nothing in the lobby checks that every player runs the same build. A different build shows up later, as a desync or a crash.
- **Host:** the host can't change during a game.
- **Speed:** the slowest PC caps the speed, and a speed change applies about half a second later.
- **Saves:** Quick Load and the game's autosave are off during a session.
- **Battles:** a battle can't be restarted in a multiplayer game.
- **Titles:** in a session each title is worth the base 0.5. The plain game counts the races your profile has won with.
- **Resync:** a world resync while a world-battle prompt is open leaves the PC that reloads without that prompt.
- **Other mods:** SOSDET replaces game classes. Other mods that change the same classes or the simulation are untested with it.
